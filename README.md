# Cryptography-and-Python-basics
Cryptography and Python basics: encryption, decryption, character encoding, print statements, and loops.
Cryptography and Python Basics
Overview
This project contains coursework exercises covering basic cryptography concepts and Python programming fundamentals.

Topics Covered
Encrypting and decrypting my name.
Encrypting and decrypting the phrase “Cyber Security”.
Decoding and encoding encrypted letters and numbers.
Encrypting the phrase “Hello Student”.
Using Python print statements to display output.
Using loops to print numbers from 1 to 10.
Learning Objectives
Understand basic encryption and decryption concepts.
Practice working with encoded characters and numbers.
Learn basic Python syntax and output statements.
Practice loops and number sequences.
Purpose
This project was created as part of my cybersecurity studies to practice introductory cryptography and Python programming.
